Usar P0 para bloqueo esencial o consecuencia grave; P1 para confusión relevante
o inaccesibilidad; P2 para fricción recuperable; P3 para consistencia menor.
Marcar las hipótesis que aún necesitan reproducción. No dar severidad crítica
a preferencias estéticas ni repetir el mismo problema por cada componente.
